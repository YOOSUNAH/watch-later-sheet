# 📱 나중에 다시 보고싶은 영상들 - 모바일 링크 저장기

구글 스프레드시트와 연동되는 가볍고 빠른 모바일 전용 웹앱입니다.  
스마트폰에서 유튜브나 웹 서핑 중 마음에 드는 링크를 복사해 **터치 두 번(붙여넣기 ➔ 저장)**으로 내 구글 시트에 차곡차곡 보관할 수 있습니다.

---

## 🌟 주요 특징

1. **내 시트 구조 맞춤형 저장**
   - 시트에 이미 있는 체크박스 열(A열)을 감지하여 엉뚱한 곳에 추가되지 않고, 비어있는 행을 찾아 차례대로 `[체크박스, 카테고리, 링크]`를 저장합니다.
   - 이미 4~9행처럼 카테고리만 있고 링크가 비어있는 항목이 있다면 그 자리를 우선 채워줍니다.
2. **모바일 최적화 편의 기능**
   - **카테고리 칩 선택**: 엄지손가락으로 탭하기 쉬운 칩(Chip) 버튼.
   - **+ 직접 추가**: 목록에 없는 새 카테고리도 현장에서 즉시 입력 가능.
   - **📋 클립보드 원터치 붙여넣기**: 복사한 링크를 입력창에 손댈 필요 없이 버튼 하나로 쏙 붙여넣기.
   - **원클릭 연속 저장**: 저장 완료 즉시 입력창이 비워지고 다음 링크를 바로 입력할 수 있습니다.

---

## 🚀 3분 완성 설치 및 배포 가이드

### 1단계: 스프레드시트에서 Apps Script 열기
1. 링크를 저장할 본인의 구글 스프레드시트를 엽니다.
2. 주소창 URL에서 `/d/` 와 `/edit` 사이의 문자열이 **스프레드시트 ID**입니다. 복사해 두세요.  
   예: `https://docs.google.com/spreadsheets/d/`**`여기가_ID`**`/edit`
3. 상단 메뉴에서 **[확장 프로그램]** ➔ **[Apps Script]**를 클릭합니다.

---

### 2단계: 코드 복사 및 파일 추가
1. **`Code.gs` 내용 교체**:
   - 편집창에 열려있는 `Code.gs`의 기존 내용을 모두 지우고, 이 프로젝트의 [`Code.gs`](Code.gs) 파일 내용을 복사해서 붙여넣습니다.
2. **`index.html` 파일 생성**:
   - 좌측 사이드바의 **[파일] 옆 `+` 버튼**을 클릭한 뒤 **[HTML]**을 선택합니다.
   - 파일 이름에 `index`를 입력하고 Enter를 누릅니다 (`index.html` 생성).
   - 생성된 파일의 기본 내용을 모두 지우고, 이 프로젝트의 [`index.html`](index.html) 파일 내용을 복사해서 붙여넣습니다.
3. **스프레드시트 ID 입력**:
   - `Code.gs`와 `index.html`에 있는 `YOUR_SPREADSHEET_ID`를 1단계에서 복사한 본인 시트 ID로 모두 바꿉니다.
     (`Code.gs`의 `SPREADSHEET_ID` 상수, 그리고 두 파일의 "시트 열기" 링크)
4. 상단 도구 모음의 **💾 저장(디스크 아이콘)**을 누릅니다 (단축키: `Ctrl + S` / `Cmd + S`).

---

### 3단계: 웹 앱(Web App) 배포하기
1. 오른쪽 상단의 파란색 **[배포]** 버튼 ➔ **[새 배포]**를 클릭합니다.
2. 좌측 톱니바퀴 아이콘(유형 선택)을 누르고 **[웹 앱(Web app)]**을 선택합니다.
3. 다음 옵션을 설정합니다:
   - **설명**: `영상 저장기 v1` (원하는 이름)
   - **다음 사용자 권한으로 실행**: **`나(본인 구글 계정)`**
   - **액세스 권한이 있는 사용자**: **`모든 사용자(Anyone)`**  
     *(⚠️ 중요: '모든 사용자'로 설정해야 휴대폰에서 접속할 때마다 구글 계정 재로그인을 요구하지 않아 편하게 사용하실 수 있습니다. 혼자만 쓰는 링크이므로 URL을 공유하지 않는 한 본인만 접속하게 됩니다.)*
4. 하단 **[배포]** 버튼을 클릭합니다.
5. **권한 승인 창이 뜨는 경우**:
   - **[액세스 승인]** 클릭 ➔ 본인 계정 선택 ➔ "Google에서 확인하지 않은 앱" 경고가 뜨면 좌측 하단 **[고급(Advanced)]** 클릭 ➔ **`...로 이동(안전하지 않음)`** 클릭 ➔ **[허용]** 클릭.
6. 배포가 완료되면 화면에 나타나는 **웹 앱 URL** (예: `https://script.google.com/macros/s/.../exec`)을 복사합니다.

---

## 🔒 보안 주의사항

- **웹 앱 URL(`https://script.google.com/macros/s/.../exec`)은 비밀번호처럼 다뤄주세요.**  
  '모든 사용자' 권한으로 배포하면 이 URL을 아는 사람은 누구나 내 시트에 내용을 쓸 수 있습니다.
  README, 이슈, 커밋, 공개 채팅방 등에 올리지 마세요.
- URL이 노출됐다면 Apps Script 편집기의 **[배포] ➔ [배포 관리]**에서 해당 배포를 **보관(Archive)**하고 새로 배포하세요. 새 URL이 발급됩니다.
- 이 저장소의 코드에는 스프레드시트 ID 대신 `YOUR_SPREADSHEET_ID`가 들어있습니다. 본인 ID를 넣은 코드는 Apps Script 편집기에만 두고, 다시 커밋하지 마세요.

## 📱 스마트폰 홈 화면에 '진짜 앱'처럼 추가하기

복사한 웹 앱 URL을 스마트폰 카카오톡 '나와의 채팅'이나 메모장에 보낸 뒤 브라우저로 엽니다.

### 🍎 아이폰 (Safari)
1. Safari 브라우저에서 웹 앱 URL로 접속합니다.
2. 화면 하단 중앙의 **공유 버튼(네모에 위쪽 화살표 ↑)**을 누릅니다.
3. 메뉴를 아래로 내려 **[홈 화면에 추가]**를 선택합니다.
4. 이름을 `영상 보관` 등으로 지정하고 **[추가]**를 누르면 바탕화면에 앱 아이콘이 생성됩니다.

### 🤖 갤럭시/안드로이드 (Chrome 또는 삼성인터넷)
1. Chrome 브라우저에서 웹 앱 URL로 접속합니다.
2. 우측 상단의 **더보기 메뉴(점 3개 ⋮)**를 누릅니다.
3. **[홈 화면에 추가]** 또는 **[앱 설치]**를 선택합니다.

---

## 💡 실사용 흐름 (초간단)
1. 유튜브나 인스타그램 등에서 보고 싶은 영상을 발견하면 **[공유] ➔ [링크 복사]** 클릭
2. 스마트폰 홈 화면의 **[영상 보관]** 앱 아이콘 터치
3. 원하는 **[카테고리]** 선택 (새 카테고리라면 '직접 추가')
4. **[📋 클립보드 붙여넣기]** 터치 ➔ **[시트에 저장하기]** 터치
5. 0.5초 만에 구글 스프레드시트에 자동 기록 완료! 🎉
